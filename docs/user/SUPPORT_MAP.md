# Support Map

## User Support Channels

1. Authentication and access
   - Owner: Clinic Administrator
   - Typical issues: account locked, wrong role, access denied

2. Medical data workflow
   - Owner: Clinical Operations Lead
   - Typical issues: patient/case update mismatch, workflow confusion

3. Technical platform issues
   - Owner: Engineering Support
   - Typical issues: API error, upload failure, timeout

## Information to include in a support request

- Timestamp
- Endpoint or screen used (`/login`, `/register`, `/dashboard`, API path)
- Patient or case ID (if applicable)
- Error message
- Preferred language: English or French

## SLA Targets (recommended baseline)

- Critical patient-care blockers: under 1 hour response
- Major workflow issue: under 4 hours response
- Minor issue: next business day response
